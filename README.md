# SQL Interview Preparation using SQLite

Welcome to my SQL Interview Preparation repository!

This repository documents my journey of learning and practicing SQL from **Beginner to Advanced** using **SQLite**. The goal is to strengthen my SQL skills for **Data Analyst** interviews through structured, topic-wise practice.

---

## 🎯 Objectives

- Learn SQL concepts step by step
- Practice writing clean and readable SQL queries
- Solve interview-style SQL questions
- Build a strong SQL portfolio on GitHub
- Prepare for Data Analyst interviews

---

## 🛠️ Technologies Used

- SQLite
- SQLite Online IDE
- Git
- GitHub

## 📊 Dataset

A custom E-Commerce Sales database is used throughout the repository.

Tables include:

- Customers
- Products
- Categories
- Employees
- Orders
- Order_Items

Using the same dataset for every topic helps simulate real-world business scenarios and makes it easier to understand relationships between tables.

---

## 🚀 Learning Approach

For each topic, I follow this workflow:

1. Understand the SQL concept
2. Solve beginner to interview-level questions
3. Test queries using SQLite Online IDE
4. Write clean and formatted SQL solutions
5. Upload the completed work to GitHub
